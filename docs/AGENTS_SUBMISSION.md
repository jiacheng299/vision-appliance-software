## 与已有实现的边界

- 原有看板、运行状态、视频源、系统设置及账号功能保留；新增智能体配置、工作流、公共适配器、模拟演示和相关测试。

- 新增事件契约命名为 `AgentEventDTO` / `AgentEventPage`，避免与基础模块的 `EventDTO` / `EventPage` 重名。
- 数据库迁移只创建智能体自有表和扩展这些表；不删除基础模块的表或数据。原有依赖锁定版本保持不变，新增 hls.js。

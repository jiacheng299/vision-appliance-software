# 智能体管理第一轮开发记录

日期：2026-10-20。工作分支：`codex/agent-management`。起点：`92b6cf7`。

## 本轮结果

完成真实 Agent/Revision 草稿管理的纵向闭环：创建 → 卡片 → 详情 → 编辑保存 → 刷新读取 → 复制版本 → 查看原版。
这不是完整智能体模块验收。原任务书 B-02、B-06 等依赖真实运行/视频/事件的用例尚未满足。

## 设计选择

- 用户本轮明确授权开始智能体开发，启用原本禁用的智能体导航；其余两个业务入口保持原状。
- 沿用模块化单体和 Foundation 的 snake_case、row_version、Cookie+CSRF、错误格式。
- 按主规格建议保留 channels[] 多通道配置，首轮仅草稿，不承诺多路实际执行能力；需与 A/负责人共同评审。
- Agent/Revision 模型单独放在 agents 模块；sources 只新增公开的只读引用解析函数。
- 不接管 Run/Event/Model 表，不通过修改前端状态制造 running。
- 写事务串行化仅覆盖定义和回执，不执行耗时推理；并发旧版本返回 409，幂等回执随资源原子写入。
- 克隆版本不修改原版本；published 状态有写保护，但不提供绕过验证的发布入口。
- 创建和克隆保留同一次请求的幂等键以应对超时。当前回执无自动过期，需后续规划保留策略。
- 浏览器实测发现中文请求超时、英文及直接 HTTP 正常，智能体 SDK 增加标准 JSON Unicode 转义后，中文创建与保存均通过；DTO 和数据库中的文字保持中文。

## 已知限制与下一步

- 模型能力目录、可执行性、确认发布和运行服务未接入。只保留验证端点的明确 503；没有启停/应用成功假实现。
- 报警、证据、反馈、漏报、复测和导出未实现；详情相应区域明确说明服务未接入。
- 播放复用现有 Source 预览组件；未实现 WebRTC/HLS 增强、检测框、运行画面定位和播放会话续期。
- ROI 首轮在真实源缩略图上绘制，不支持实时源绘制、缩放、拖拽顶点或视频时间轴。
- 未实现归档/删除和跨模块运行引用保护；没有破坏历史数据的入口。
- 列表按源过滤读取最新配置；版本列表未分页，规模增大后需优化查询和通道规范化。
- 各角色继承当前基础版工作空间权限，没有新增按用户划分的视频访问授权；更细粒度授权由公共鉴权服务统一落实。
- 前端测试用 Mock 隔离真实服务；未额外搭建独立运行/报警的演示服务。测试替身不能作为真实推理验收。
- 还需 A/B/负责人评审多通道设计、公开字段、公共服务负责人和分阶段验收范围。

下一轮优先落实能力校验、验证/确认的不可变快照，再接 RunController 与可查询的应用作业。发布与运行必须分开，不用 latest_revision 代替实际运行版本。

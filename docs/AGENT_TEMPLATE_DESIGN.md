# 智能体模板与任务实例（Issue #7）

本次用户最终确认：智能体卡片是可复用的业务模板；任务选择已发布模板获得模型和配置；旧任务固定创建时的模板版本；配置项池由开发者维护，用户不能新增配置项。

## 实现边界

- 新增模板、不可变已发布版本及任务关联表。执行任务继续复用既有 Agent/Revision/Run 端口，模板和任务使用不同资源标识。
- 模板不绑定具体视频，任务按既有要求选择单个视频并独立配置区域与录像范围。卡片汇总所有关联任务及其视频源，历史多通道任务保持兼容。
- 模板中选择一个模型，底层保留模型所需的版本及配套执行模板引用，界面不要求用户重复选择技术模板。
- 参数目录集中在服务端代码中维护。提供检测对象、触发规则、持续时间、置信度、数量、区域占比、方向、颜色、速度、距离、工作时段、报警间隔等可选项及类型/范围/单位/枚举定义。用户只能选择目录项目和设置值。
- 任务保留模板版本引用及完整参数快照。模板发布新版本不重写旧任务。配置项选择、模型引用和模板版本不能通过任务保存接口被替换或伪造。
- 保存参数不等于模型支持。未声明支持的参数在验证/启动阶段明确阻止，不能丢弃条件后返回可执行。模拟演示继续明确标记。
- 保留自然语言规划、模型管理与旧任务编辑端口，历史任务不删除；新任务的默认入口改为模板选择流程。

## 实施顺序

1. 参数目录、模板/任务 DTO、数据库迁移与旧数据登记。
2. 模板版本、发布、任务实例化和聚合查询 API；类型、范围、不可变版本与幂等测试。
3. 智能体模板卡片、模板编辑器和关联任务/视频视图。
4. 任务创建接入模板选择及动态参数编辑，保留旧任务兼容入口。
5. 契约生成、全量回归、隔离浏览器验收与操作说明。
6. 同步最新远程，处理冲突、验证后普通合并并推送 main。

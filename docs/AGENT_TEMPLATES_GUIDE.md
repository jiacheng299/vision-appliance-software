# 智能体模板与任务操作说明

更新：2026-10-27。本说明采用用户最终确认的结构，覆盖此前“每个智能体卡片就是一个运行任务”的界面说明。

## 名称与关系

| 名称 | 含义 | 火灾检测示例 |
|---|---|---|
| 智能体模板 | 可重复使用的业务定义，指定模型及可配置条件 | 火灾检测模板 |
| 模板版本 | 发布后不可修改的模型和配置快照 | v1 的置信度默认 0.8，v2 默认 0.9 |
| 任务 | 使用一个已发布模板版本，对具体视频执行检测 | 一号仓库火灾任务 |
| 视频源 | 摄像头直播或已导入录像 | 仓库摄像头、warehouse.mp4 |
| 通道 | 运行配置中的规则与输入单元；新模板任务生成一个单视频通道 | 一号仓库任务的检测通道 |
| 运行 | 任务验证并确认后发起的一次实际执行 | 某次启动与对应事件记录 |

智能体管理中的卡片现在是模板。点击“管理模板与任务”可查看该模板关联的任务、各任务原始模板版本，以及所有任务曾使用过的视频源；同一视频源去重统计。历史多通道、多视频任务保留原结构。

## 按顺序操作

1. 在“视频源管理”导入录像或登记摄像头，等待探测完成。
2. 进入“智能体管理”，点击“新建智能体模板”。右侧面板填写模板名称、业务说明，并选择模型。
3. 从“选择配置项”中选择需要的项目，例如置信度阈值、最小目标数量、监测时段、重复报警间隔。设置默认值及“任务必填”约束。项目由开发者维护，用户不能新增项目或枚举选项。
4. “保存草稿”允许继续编辑；“保存并发布”生成可供任务选择的只读模板版本。模型支持多个对象或规则时，需从配置项中明确选择对象与规则。
5. 在模板卡片或模板详情点击“创建任务”，也可以直接打开“任务创建”。选择已发布的模板、填写任务名称、选择一路视频，按需配置检测区域和录像范围，并填写模板开放的条件值。
6. 点击“验证任务”。结果可执行时，核对模板版本、视频范围及条件，勾选确认后“确认启动”。请求受理后等待操作完成；保存草稿或发布模板均不会启动检测。
7. 返回模板详情的“关联任务”，打开任务查看画面、报警、配置和运行历史。

检测区域至少三个不共线点，依次点击后再点击起点附近闭合，最后“保存区域”。近邻误点自动吸附；未闭合或边界交叉的区域不能保存。

## 模板修改与旧任务

发布 v1 后修改模板，会生成 v2 草稿。发布 v2 后，新任务默认使用 v2；已经创建的任务仍使用 v1 的模型、配置项目和快照，不自动升级，包括尚未启动的任务草稿。旧任务可以修改已开放项目的值，但修改后需要重新验证。

需要采用新版模板时，应使用新版模板新建任务。归档模板只阻止新任务创建，不删除已有任务或运行记录。

迁移时，每个旧智能体登记一个待核对的模板草稿，并将原智能体作为历史任务关联。旧配置、运行和验证记录不重写；旧配置包含多通道时，模板草稿只从首个通道提取初始建议，需人工核对后发布，不能视为完整业务的自动迁移。历史任务仍可从“历史任务入口”或关联任务进入原工作空间，保留既有自然语言执行方案与多路配置。

## 模型与选项池的边界

当前目录包含 24 个配置项，覆盖对象、规则、持续时长、置信度、数量、面积比例、运动方向、速度、距离、颜色、尺寸、时段、报警等级、报警间隔、事件合并、采样和跟踪等条件。

目录中存在某个选项，不代表每个模型都能处理它。模型服务必须声明支持的 `parameter_keys`，执行器也必须支持参数契约。未支持的条件会阻止验证或启动，不能省略条件后执行。真实模式仍依赖团队接入的模型、推理及运行服务；模拟模式仅演示配置传递、版本隔离与状态流程，不证明火灾识别效果。

## 代码定位

- `backend/app/modules/agent_templates/`：模板、版本、任务关联、聚合查询。
- `backend/app/shared/monitoring_parameters.py`：开发者维护的选项池、类型、枚举及范围校验。
- `backend/alembic/versions/0007_agent_templates.py`：新增表及历史配置登记。
- `frontend/src/modules/agents/AgentTemplatesPage.vue`：模板卡片。
- `frontend/src/modules/agents/TemplateEditor.vue`：右侧模板编辑器。
- `frontend/src/modules/agents/TemplateWorkspacePage.vue`：关联任务、视频源、模板版本。
- `frontend/src/modules/agents/ParameterFields.vue`：模板与任务共用的动态配置表单。
- `frontend/src/modules/task-create/TemplateTaskCreatePage.vue`：按模板创建、验证与启动任务。

开发者新增项目时，在目录中定义稳定 key、类型、单位、范围和枚举，补充边界测试，并在支持该项目的真实模型/执行器中实现语义。公共契约变化后重新生成 OpenAPI 和前端类型。无需修改用户界面中的固定字段列表。

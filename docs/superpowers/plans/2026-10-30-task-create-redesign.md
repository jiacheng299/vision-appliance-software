# 任务创建页改版实施计划

> **For agentic workers:** 按六项任务逐步实现，每项先验证失败用例，再实现并提交；交付保留本地提交，不推送。

**Goal:** 按用户确认的两张原型，将当前任务创建页改为选模板、配置多视频、验证启动三步流程。

**Architecture:** 保留已有模板、草稿、区域、参数、验证及运行API。页面负责步骤状态；模板选择、视频工作台、条件面板和核对页各自保持清晰边界。自然语言仅保留禁用入口，不调用已有匹配API。

**Tech Stack:** Vue 3、TypeScript、Naive UI、Vitest。

**Spec:** 本聊天中已确认的原型及用户补充：第一步先确定模板，手动选择开放，自然语言自动匹配已有模板暂不实现；第二步沿用三栏工作台，仅改变当前页面。

## 约束

- 不修改全局导航、其他页面、后端接口、用户任务和运行配置。
- 保留1至16路输入、原模板版本、幂等保存、多路独立区域和未保存离开保护。
- 保存或验证不能自动启动，验证过期或配置变化后不可确认启动。
- 每个提交包含对应验证，六个中文提交，暂不push。

## 1. 模板选择组件

Files: `frontend/src/modules/task-create/TemplateSelection.vue`、`frontend/tests/template-selection.test.ts`。

- [ ] 测试搜索已发布模板、选择事件、禁用自然语言及只读旧版本。
- [ ] 运行 `npm test -- tests/template-selection.test.ts` 观察新组件缺失失败。
- [ ] 实现 props `templates`、`selectedId`、`version`、`disabled`，emit `select(id)`；只显示已发布且未归档模板。
- [ ] 单测通过后提交 `feat: 新增任务模板选择界面与匹配预留入口`。

## 2. 三步流程

Files: `TemplateTaskCreatePage.vue`、`template-task-create.test.ts`。

- [ ] 测试未确认模板不能进入配置；确认前不调用创建或匹配API；已有草稿继续原版本。
- [ ] 删除当前页的匹配API调用，接入步骤状态 `step=0|1|2` 和第一步组件。
- [ ] 验证后进入第三步，回退不丢失配置；原业务接口与幂等key复用。
- [ ] 相关测试通过后提交 `feat: 将任务创建改为先选模板的三步流程`。

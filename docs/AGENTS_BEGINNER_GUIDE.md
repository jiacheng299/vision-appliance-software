# 智能体管理：从零开始操作

> 2026-10-27：默认界面已采用“智能体模板 → 固定版本任务 → 视频源”结构。请先阅读 [模板与任务操作说明](AGENT_TEMPLATES_GUIDE.md)。下文多通道、自然语言及旧卡片流程适用于历史任务兼容入口；旧任务不会随模板更新。

> 2026-10-22 最新结构：智能体代表业务，通道代表共享规则的监测组，每组可绑定多个视频源、按源配置区域和录像范围；详见 [通道与多视频操作说明](AGENTS_SOURCE_GROUPS.md)。该规则覆盖下文原单源通道的描述。


更新：2026-10-22。你负责的 B 模块已具备管理页面、配置发布流程、公共服务接口及独立演示。真实识别、摄像头网关和正式报告，需要与其他成员的服务联调后验收。

## 1. 先弄懂几个词

| 名称 | 可以怎样理解 |
|---|---|
| Agent（智能体） | 一个长期保存的监测任务文件夹，例如“北门监测” |
| Channel（通道） | 文件夹中的一路视频和它的监测条件 |
| Revision（配置版本） | 设置的一个版本，例如 v1 停留30秒，v2 改成60秒 |
| Validation（验证） | 检查条件是否完整、模型是否支持，并列出限制 |
| Publish（发布） | 你确认这版设置，之后它成为只读快照；此时还没有启动 |
| Run（运行） | 按某个已发布版本执行的一次分析，每一路各有记录 |
| Operation（操作作业） | 启动、停止、应用版本的处理进度；提交成功不等于处理完成 |

记住：**保存 → 验证 → 确认发布 → 启动**。四步含义不同。

## 2. 先用演示模式学习

项目根目录是包含 `start.cmd`、`frontend` 和 `backend` 的文件夹。

1. 新电脑首次使用，先按 README 安装 Python 和 Node，再双击 `setup.cmd`。
2. 双击 **`start-agents-demo.cmd`**，保持启动窗口打开。
3. 浏览器打开 **http://127.0.0.1:8004/agents**。
4. 页面直接进入智能体管理，无需建立管理员或登录。
5. 点击“加载双路模拟样例”，按下文练习；真实模式与演示模式都不需要账号。

页面顶部始终有“独立演示”标识。运行、目标框、报警、证据和导出结果都是模拟数据，画面是示意图，不能证明算法效果。

演示数据在 `.artifacts/demo-data/agent-demo/`，与普通 `var/` 分开。草稿、版本、验证和确认存进数据库；模拟运行、事件、反馈和导出作业只在内存中，重启服务后重置。

如果8004端口正在运行本次预览，直接打开网页即可；重新启动前先关闭原来的启动窗口。真实库与演示库数据隔离，切换不涉及登录。

## 3. 跟着做一遍完整流程

### 创建与启动

1. 在列表点击“加载双路模拟样例”，打开示例。包含一路模拟摄像头和一路60秒模拟录像。
2. 在“配置”查看每一路：视频源、需求文字、模型/模板、对象、规则、时长、区域。真实库可以自行创建草稿、增加通道、选择已有视频源。
3. 保存，再点击验证。缺少条件时按提示补齐；不支持或证据不足时不会放行启动。
4. 打开发布确认，阅读配置、模型版本和限制，勾选确认并发布。
5. 选择要启动的通道，提交启动。观察操作作业变为成功，再看每路实际状态。
6. “实况”可以切换通道、看实际版本、独立停止。排队、启动中、运行中、断线和失败都有文字区分。

验证有效期10分钟。配置、源版本或能力变化后需要重新验证。已发布版本不能修改；过期后复制成新草稿，再验证发布，历史照常保留。

### 修改运行中的设置

1. 复制已发布版本，得到 v2 草稿。
2. 修改并保存，例如30秒改为60秒。原 Run 此时仍按 v1 运行。
3. 验证并确认发布 v2。
4. 选择受影响通道，查看差异和旧 Run，再确认应用。每一路先停旧运行，再启动新运行。
5. 查看每路结果。部分失败时可能混合 v1、v2；以实际状态为准。

旧运行停止失败，会保留旧运行并报告失败；旧运行已停而新运行启动失败时，不会显示自动回滚成功。明确重启旧版本会产生新的 Run。

### 查看报警（人工核查暂未开放）

在“画面与报警”中点击事件，可以只读查看判断依据、实际Run/版本、截图或片段。人工核查导航已置灰，标注“当前版本暂未开放”；本版本不能提交正确/误报反馈或人工漏报。原有历史记录保留，不会删除。

### 绘制封闭监测区域

1. 进入“监测配置”，编辑草稿，选择有缩略图的视频源。
2. 沿边界顺时针或逆时针点击至少三个点。绿色点是起点。
3. 相邻点击距离约10个屏幕像素以内时自动合并，避免手抖产生短边。
4. 点击绿色起点附近，系统吸附并闭合；没有闭合不能保存区域。
5. 交叉、折返重叠、重复顶点或零面积会提示错误；用“撤销点”修正。
6. 闭合后可“撤销闭合”继续调整，或点“保存区域”，再保存整个配置草稿。

已有区域以闭合多边形读取，不要求再画一遍；保存数据不重复记录起点，最后一条边自动连回第一个点。

编辑配置时点击左侧灰色遮罩或按Esc可关闭抽屉，有未保存内容会先确认，保存过程中不能关闭。

### 历史、复测与导出

1. “历史”查看版本和各次运行，按一次旧 Run 创建复测草稿，只复制该路实际配置和录像范围。
2. 修改、验证、发布、启动后，选择基准与新运行比较。展示原始计数及可比性限制，不凭少量反馈推算准确率。
3. “报告与导出”选择实际运行及报告、截图、片段等内容；也可明确不导出。
4. 选择浏览器下载，或公共服务允许的主机目录别名，不填写服务器任意路径。
5. 查看进度，可取消，失败后沿用原快照重试，成功后再下载。

**演示下载的是 `MOCK_NOT_A_REPORT.json` 操作快照，有明确警告，不是正式报告、截图或视频。** 演示主机保存只演练状态，不实际写主机目录。

### 故障练习与归档

演示详情可选择模型不可用、视频断流、事件断线、资源排队、停止失败、启动失败、单路异常、重复事件、证据不足、导出失败。练完切回正常场景。

归档前先停止运行和待处理启动。归档是隐藏而非删除，列表切到已归档可以恢复，历史保留。

## 4. 真实模式

新终端双击 **`start.cmd`**，打开 http://127.0.0.1:8000/agents 。默认关闭演示，不自动填入模拟报警。

当前真实库可以保存、复制和管理配置。模型、运行、事件、媒体、报告服务未连接时显示未接入/不可用，验证和执行不会假成功。其他成员实现后，通过 `AgentServices` 接入，见 `AGENTS_API.md`。

本机8002是独立真实预览库，保留以前草稿，与默认 `var/` 不同。日常学习优先8004。

## 5. 你该看哪些代码

| 文件（前端位于 frontend/src/modules/agents） | 作用 |
|---|---|
| AgentsPage.vue | 卡片、搜索、筛选、归档 |
| AgentWorkspacePage.vue | 详情总页面 |
| WorkflowPanel.vue、RevisionEditor.vue | 验证发布与配置表单 |
| MonitorPanel.vue、RunPlayer.vue | 分路状态、播放、区域与目标框 |
| EventsPanel.vue、EventDrawer.vue、MissedDialog.vue | 报警、证据、反馈和漏报 |
| HistoryPanel.vue、ExportsPanel.vue | 历史复测和导出 |
| backend/app/modules/agents/service.py、workflow.py | 保存规则、发布门槛和操作编排 |
| integrations.py、contracts.py（同后端目录） | 与其他成员约定的方法和数据格式 |
| demo.py（同后端目录） | 隔离模拟服务，不能当真实推理引擎 |
| tests/backend/test_agent_workflow.py | 防止关键流程被改坏的检查 |

修改习惯：新建分支 → 小步修改 → 测试与构建 → 查看差异 → 提交。界面文字从 Vue 文件开始学，业务规则看后端，字段查 OpenAPI，不需要先读懂整个仓库。

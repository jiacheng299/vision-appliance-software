## 整合时补齐的衔接

- 新建智能体抽屉继续使用共享 UUID 实现，局域网 HTTP 下可创建草稿。
- 抽屉和编辑器新加的通道默认使用固定模板模式，任务创建页与智能体配置保持一致；旧配置仍兼容。
- 看板不再把任务与事件数量写死为 0。运行/事件所有者提供公开 `AgentServices.summary(actor_id) -> ExecutionSummary`；看板、运行概况和最近事件列表共用该端口。A 与看板均不读取或写入执行器的数据库。
- 适配器未提供汇总时计数为 null，显示未知/服务未接入；不能把依赖故障表示为零个事件。运行与报警可独立不可用。
- 汇总带 `data_origin`。模拟统计与智能体详情来自同一服务，并保持显式模拟提示。
- 最近事件最多返回 50 条，看板展示最近 5 条；按上海自然日计算今日事件，与智能体事件页保持一致。完整历史在智能体详情按运行查看。
- 最近事件带所属 agent_id，可跳回对应智能体核查运行和证据。

## 查看方式

Windows 沿用根 README：先安装既有依赖，再运行 `start-agents-demo.cmd`。没有模型服务时应使用此显式演示入口。可在任务创建或智能体管理加载模拟样例，在模型管理绑定模拟多模态用途，再练习自然语言未匹配路径。正式模式入口仍是 `start.cmd`。

本次在线验收使用隔离的演示数据库，四路彩色测试录像为 FFmpeg 合成内容；火源事件是显式模拟，录像中没有真实火源识别。运行、媒体和模型均不接触正式数据。演示数据库、测试录像和本机日志未加入 Git。

当前远程预览环境中，资源采样/状态通知部分不可用；页面保留未知状态及定时刷新。摄像头现场连接、GPU 使用率、真实模型分析与推理仍需团队服务及目标机器验收。该预览证明已整合的界面与模拟业务衔接，不证明识别精度或硬件性能。

# 基础框架验收文档

实施日期：2026-10-18；最终验收记录：2026-10-19。对应仓库 `jiacheng299/vision-appliance-software`，基础框架版本 0.1.0。

## 1. 本次交付范围

依据主规格与五张原型，交付 Vue3/TypeScript/Naive UI 前端及 FastAPI/SQLAlchemy/Alembic/SQLite 后端、独立媒体 Worker、统一认证/错误/契约及 Windows 安装启动工具。

本次可验收四页：快速监控看板、运行状态、视频源管理、系统设置。七个一级导航保持一致；任务创建、智能体管理、模型管理暂不生成，导航明确不可用。这是用户指定的阶段范围，不能据此声称完整主规格已全部验收。

## 2. 如何启动与验收

在安装 Python 3.13 x64 和 Node.js 22.12+ / 24 后，双击根目录 `setup.cmd`；出现完成提示后双击 `start.cmd`。浏览器打开 **http://127.0.0.1:8000**。若端口占用，用 `start.cmd --port 8002`，不要结束其他程序。

首次建立管理员账号，密码至少 12 位；请自行设定，不存在通用默认密码。后续访问需要登录。当前浏览器与服务主机在同机；本轮默认不开放公网，不把浏览器下载位置混同服务主机目录。

## 5. 已知阶段限制

- 当前尚无任务/智能体/模型管理页面，不存在可启动的算法监测任务。运行、事件、模型空查询为后续接入契约，不是推理效果验收。
- 时区、自动重连、保留期限及报告格式等后续执行策略已可保存，尚未全部接入执行；界面时间目前跟随浏览器时区，会话有效期修改对新会话生效。
- 没有部署 MediaMTX、本地语言模型、多模态模型或专用小模型；RTSP 测试目前仅连接/协议诊断，不是实际解码与播放能力证明。相应状态明确显示未就绪。
- GPU 没有采集器时显示未知，不填 0%。授权/许可证没有配置，不伪造已授权信息。
- 本地文件流程使用真实 FFprobe/FFmpeg，上传探测/预览成功不等于视觉算法验证通过。
- 完整 FR-12–32 中涉及需求理解、确认启动、智能体版本、多路推理、反馈/漏报、复测及报告导出的部分由后续阶段接入。模型与模板配对、离线模型包及目标硬件长稳/精度尚未验收。
- 目前交付联网安装工具与安装后本地运行能力；不声称已经提供主规格要求的完整物理离线安装介质。受控局域网 HTTPS、现场媒体接入和最终角色管理需部署阶段验证。
